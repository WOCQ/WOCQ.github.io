SIGI - Sistema de Gestión de Incidentes TI

Estructura del proyecto:
- index.html: estructura de la aplicación.
- css/styles.css: estilos, diseño adaptable y presentación visual.
- js/app.js: interacciones, registro/edición/eliminación de tickets,
  filtros, base de conocimientos, reportes y almacenamiento local.

Cómo ejecutar:
1. Extrae la carpeta SIGI_Proyecto.
2. Mantén la estructura de carpetas y archivos.
3. Abre index.html con Google Chrome.

Importante:
Los datos de este prototipo se guardan en localStorage del navegador.
No requiere instalar dependencias ni ejecutar un servidor.
